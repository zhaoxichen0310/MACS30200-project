# MACS 30200 Final Project

This repository contains my final project for MACS 30200. The project examines whether time spent on digital leisure is associated with lower face-to-face socializing and lower subjective well-being using ATUS data.

## Research Questions

This project focuses on two related research questions:

1. Does spending more time on digital leisure crowd out time spent in face-to-face socializing?
2. Is more digital leisure associated with lower subjective well-being?

## Repository Structure

- `MACSS_30200_final.ipynb`: Main analysis notebook with data cleaning, descriptive statistics, visualizations, regression models, and final interpretation.
- `Data/`: Folder containing the datasets used in the project.
- `figures/`: Folder containing exported figures and tables generated from the notebook.
- `README.md`: Overview of the project and repository contents.
